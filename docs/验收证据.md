# 题目2 · 验收证据

> 本目录下的日志都是**本机实测**（2026-11-18，WSL2 + ROS 2 Humble + gz-sim 6，无 GUI 模式复跑）。
> 每条都给了复现命令。

| 小题 | 证据文件 | 复现命令 |
|---|---|---|
| （1）全向控制 6/6 | `evidence/omni_check.log` | `ros2 launch diff_bot_description omni_sim.launch.py` + `python3 tools/verify_omni.py` |
| （2）A→B 避障 | `evidence/A2B_run.log` | `ros2 launch diff_bot_control gz_follow_ab_mymap.launch.py` |
| （3）建图 | `models/map_gz_clean.pgm` / `results/map_gz_clean_preview.png` | `ros2 launch diff_bot_control gz_slam.launch.py patrol:=true` |
| 附加题导航 3/3 | `evidence/nav_goals.log` | `gz_navigation.launch.py map:=...map_gz_clean.yaml` + `nav_goal_demo` |

## 关键数字

| 项 | 结果 |
|---|---|
| 全向 6 个方向 | 前进 +0.759 m / 后退 -0.758 m / 左横移 +0.729 m / 右横移 -0.728 m / 左转 +71.2° / 右转 -71.2° — **6/6** |
| A→B | 路径 6.172 m，最小间距 **0.259 m**，终点误差 0.15 m，约 31 s |
| 地图 | 214×201 @0.05 m，占用 4.4% / 空闲 53.1% / 未知 42.5%；四周墙体闭合，中央长条与四角圆柱可辨（预览图见 `results/map_gz_clean_preview.png`） |
| 导航 | 3 个目标点全部到达（34.3 s / 16.9 s / 57.4 s） |

## 说明

- 全向判定用的是 Gazebo **世界真值位姿**（`/gz_ground_truth`），不是 `/odom`（odom 由轮速推算，会自证）。
- 导航目标点由 `tools/pick_goals.py` 从地图里自动挑（可达连通域 + 净空 ≥0.45 m + 彼此分散 ≥1.8 m），避免"碰巧能到"。
- 地图统计按 ROS 语义：`0`=占用、`254`=空闲、`205`=未知；未知占了 42.5%，都在墙外，属正常。
